03 How I work

Four rules every site follows.

01

Real content only

Copy and photos come from you, not stock libraries. Anything not yet done is labelled as planned. Visitors trust what they can verify.

02

No lock-in

Plain HTML, CSS and JavaScript. No page builder, no subscription, no framework to update. It runs on any host, today and in ten years.

03

Accessible by default

Keyboard navigation, visible focus, readable contrast, reduced-motion support and proper labels, checked against WCAG 2.2 before launch.

04

Built to hand over

Every editable spot is marked in the code and explained in a plain-language guide, so you can change a phone number without calling me.

04 Process

From first call to launch.

  1. Step 1

    Listen

    We talk about your business, your clients and what the site must achieve. I gather your brochures, photos and existing material.

  2. Step 2

    Design

    A visual concept built around your work, with page structure and copy, reviewed together before any code is written.

  3. Step 3

    Build

    Hand-coded, tested on phones and desktops, in both languages, with accessibility and speed checks along the way.

  4. Step 4

    Launch & hand over

    I put the site online, set up search basics and give you an editing guide. The code is yours.
